## Codebase Patterns
- Keep SvelteKit configuration in `svelte.config.js`; use `vite.config.ts` only to register Vite plugins such as Tailwind and `sveltekit()`.
- Remote functions require both `kit.experimental.remoteFunctions: true` and `compilerOptions.experimental.async: true`.
- Prisma 7 keeps the SQLite datasource URL in `prisma.config.ts`; `schema.prisma` only declares `provider = "sqlite"`.
- Generate Prisma Client into ignored path `src/generated/prisma` with the `prisma-client` generator, then import from that generated client path in future server-side data access.
- Instantiate Prisma 7's generated SQLite client with `@prisma/adapter-better-sqlite3`; a bare `new PrismaClient()` fails at runtime.
- Keep `.remote.ts` exports limited to remote functions; put reusable helpers, schemas, and Prisma operations in non-remote modules.
- Validate remote function write inputs with a Standard Schema library such as Valibot before calling Prisma.
- Use `src/lib/margins.ts` as the shared source for product margin calculations so UI display and CSV export stay consistent.
- Use `src/lib/product-table.ts` for editable product row defaults, row margin projection, and margin tone thresholds that table-adjacent features need to share.
